# Polarized by Design

A numerical study of a minimal opinion-dynamics model in which competing
persuasion and adaptive trust produce either **consensus** or
**polarization** on synthetic social networks (Erdős–Rényi,
Watts–Strogatz, Barabási–Albert).

The full model specification lives in
[`docs/Rewriting_Toy_Model.pdf`](docs/Rewriting_Toy_Model.pdf); this README
summarises it, catalogues the code, and shows how to reproduce every
figure.

---

## 1. The model

Let the social graph be an undirected graph `G = (V, E)` with `N = |V|`
nodes. At each discrete time step `t ∈ ℕ₀`:

- **Opinions.** Every node `i` carries one of two labels

  `xᵢ(t) ∈ {F, D}` (Fake-believer / Debunker).

- **Edge weights.** Every edge `ij ∈ E` carries a trust weight
  `wᵢⱼ(t) ∈ [0, 1]`.

- **Stubbornness.** Every node has a parameter `Sᵢ ∈ [1, 100]`.
  Larger `S` means more resistance to being flipped.

### 1.1 State update (synchronous)

A disagreeing neighbour `j` tries to flip `i` with probability
`wᵢⱼ / Sᵢ`. Independence of attempts gives the one-step flip probability

```
p_flip(i) = 1 − ∏_{j ∈ N(i), xⱼ ≠ xᵢ} (1 − wᵢⱼ / Sᵢ)      (eq. 3)
```

A single uniform draw `r ∼ U(0,1)` decides whether node `i` switches.
All nodes update in lockstep.

### 1.2 Hebbian weight update

After the opinion step, every edge weight is nudged by `±a` and clipped
to `[0, 1]`:

```
wᵢⱼ(t+1) = Π_[0,1] ( wᵢⱼ(t) + Δᵢⱼ(t) ),   Δᵢⱼ = +a if agree, −a if disagree
```

Agreement reinforces a tie; disagreement erodes it. The interplay
between persuasion speed and weight decay is what makes the model
non-trivial.

### 1.3 Observables

The headline observable is the **polarization coefficient** built from
the surviving cross-opinion edges `E_×(t) = {(i,j) : xᵢ ≠ xⱼ}`:

```
w̄_×(t) = mean { wᵢⱼ(t) : (i,j) ∈ E_×(t) }
P(t)   = 1 − w̄_×(t)                                        (eq. 7)
```

`P ≈ 0` means cross-opinion ties are still strong (no polarization);
`P → 1` means those ties have essentially vanished (fully fragmented
echo chambers). We also track the consensus index
`C = |2 f_D − 1|` and the cross-edge fraction `f_× = |E_×| / |E|`.

### 1.4 Dimensionless control parameter

An early finding of this project is that the two microscopic knobs — the
Hebbian step `a` and the stubbornness `S` — collapse to a single
dimensionless group

```
κ = a · S
```

Final observables plotted against `κ` fall onto a universal curve
across ER / WS / BA topologies and across average degrees `⟨k⟩ ∈ {4, 8, 16}`.
This claim is tested quantitatively in
[`experiments/collapse_test.py`](experiments/collapse_test.py) and
[`experiments/universality_test.py`](experiments/universality_test.py).


## 4. Running

Every script is a standalone CLI; `--help` lists its options. The scripts
in `experiments/` and `analysis/` import the model from `src/` via a
small `sys.path` shim, so they can be launched directly:

```bash
# A fast sanity sweep (seconds, not minutes)
python experiments/heatmap_polarized.py --quick

# Full (a, S) heatmap on an ER graph with ⟨k⟩ = 8
python experiments/heatmap_k_variable.py --graph er

# The collapse-onto-κ test (produces collapse_test.csv + figure)
python experiments/collapse_test.py

# Universality across ER / WS / BA and ⟨k⟩ ∈ {4, 8, 16}
python experiments/universality_test.py

# Re-render all heatmaps from the saved .npz grids
python analysis/plot_heatmaps.py
```

Output files land in the current working directory by default. The
curated figures and arrays in `results/` were generated this way; the
subfolder names mirror the experiment groups.

## 5. Reproducibility notes

- All simulators take `--seed` and seed every RNG explicitly.
  `polarized.py` is the reference; `polarized_fast.py` and
  `polarized_vec.py` are vectorised rewrites and reproduce `polarized.py`
  bit-for-bit when driven with the same seed and the same synchronous
  flip-RNG convention.
- `polarized_hetS.py` is a strict superset: with `Sᵢ = S` for all `i`
  its output is identical to the scalar-`S` code.
- `tests/verify_vs_reference.py` is kept for historical reference. It
  targets the pre-refactor module names (`toy_model4`,
  `heatmap_experiment`) and will not run against the current layout; the
  up-to-date equivalence checks live inside `polarized_fast.py` and
  `polarized_hetS.py` as `test_equivalence*` functions.

## 6. Symbol table

| Symbol        | Type       | Meaning                                              |
| ------------- | ---------- | ---------------------------------------------------- |
| `xᵢ(t)`       | variable   | opinion of node *i* at time *t* (F or D)             |
| `wᵢⱼ(t)`      | variable   | weight of edge *ij* at time *t*, `0 ≤ w ≤ 1`         |
| `Sᵢ`          | parameter  | stubbornness of node *i*, `1 ≤ S ≤ 100`              |
| `a`           | parameter  | Hebbian step size after (dis)agreement               |
| `w₀`          | parameter  | initial edge weight                                  |
| `κ = a · S`   | derived    | dimensionless control parameter                      |
| `P(t)`        | observable | polarization coefficient, `0 = mixed, 1 = fragmented` |
| `C`           | observable | consensus index, `|2 f_D − 1|`                       |
| `f_×`         | observable | fraction of surviving cross-opinion edges            |
